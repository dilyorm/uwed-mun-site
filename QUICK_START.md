# 🚀 UWED MUN Website - Quick Start

## Installation & Running

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Open browser to http://localhost:5173
```

## What You'll See

### Desktop Experience
- **Hero Section**: Full-screen landing with animated background and CTA buttons
- **About Section**: Mission, statistics, and animated timeline
- **Events Section**: Upcoming conferences and past events in card layout
- **Committees Section**: Interactive 6-committee grid with hover effects
- **Team Section**: Secretariat profiles with circular cards
- **Contact Section**: Registration form with UWED blue gradient
- **Footer**: Links, resources, and contact information

### Mobile Experience
- Fully responsive design
- Touch-friendly interactions
- Vertical scrolling navigation
- Optimized layouts for small screens
